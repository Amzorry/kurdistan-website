# Bundled regional boundary files

The four GeoJSON files in this directory are generated by `../../tools/download_boundaries.py` from geoBoundaries `gbOpen` ADM1 data. Run `python3 travel-map/tools/download_boundaries.py` from the project root in a network-enabled environment. The builder validates all source data and selected area names before replacing any output files.

These selected administrative areas are approximate coverage proxies, not authoritative or universally agreed Kurdistan borders. Their editable selection is documented in `travel-map/README.md` and `travel-map/tools/download_boundaries.py`. GeoJSON uses WGS84 longitude/latitude. `data/manifest.json` records source boundary IDs, years, download URLs, and licenses after a successful build.

In the current checkout the files remain empty because this environment cannot resolve `www.geoboundaries.org`; do not treat them as usable boundary data until the builder succeeds and reports non-empty outputs.

The Iraq ADM1 selection uses only source features verified by name. Halabja is listed as unavailable in the build manifest because it is not a feature in the downloaded 18-unit ADM1 source. The builder does not substitute another governorate or infer a Halabja polygon.
